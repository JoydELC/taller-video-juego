# Doom-Style Video Game Practice

## Overview

This project is a **Doom-inspired video game practice** built using **JavaScript**, **HTML**, and **CSS**. The game allows players to navigate a map, avoid enemies, and collect a gift to advance levels. It's a great way to explore basic game mechanics like movement, collision detection, and level progression.

## Features

- **Player Movement**: Use the arrow keys or on-screen buttons to move the player character around the canvas.
- **Enemy and Gift Detection**: Avoid enemies represented by emojis and reach the gift to win each level.
- **Lives and Levels**: The player has three lives per game. Hitting an enemy reduces a life, and collecting the gift moves the player to the next level.
- **Timer and Record**: Track the time it takes to complete the game, and compare it to previous records stored in the browser's local storage.

## Technologies Used

- **JavaScript**: Game logic, event handling, and dynamic rendering of game elements on the canvas.
- **HTML**: Structure of the game interface, including the canvas for rendering the game.
- **CSS**: Basic styles for layout, game elements, and modal windows.
- **Doom-Style Emojis**: Used to represent players, enemies, and other game components.

## How to Play

1. **Movement**: Move your character using the arrow keys or the direction buttons on the screen (`Up`, `Down`, `Left`, `Right`).
2. **Objective**: Avoid enemies and collect the gift to progress to the next level.
3. **Lives**: You have three lives. If you hit an enemy, you lose a life. When all lives are lost, the game resets.
4. **Winning**: Once you collect the gift at the final level, you win the game, and your time will be displayed. Compare it to your best record.
5. **Reset**: If you lose or finish the game, you can restart by clicking the **Reset** button in the modal window.
